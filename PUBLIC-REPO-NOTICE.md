# Public Repository Notice

## Purpose

This repository contains public documentation and public-facing materials for Voomytale, a voice-first AI storytelling companion for children. It exists to provide transparency about our product vision, high-level approach, and development status for startup program applications and public visibility.

## What This Repository Contains

- High-level product overview and capabilities description
- Conceptual architecture documentation
- Development roadmap and current status
- Public-facing materials

## What This Repository Does NOT Contain

The operational Voomytale product, including but not limited to:

- Proprietary story, quiz, and game content
- Content-generation methods, prompts, and review workflows
- Personalization and memory logic
- Safety and moderation policies and thresholds
- Speech and language processing methods and model choices
- Infrastructure code and deployment configurations
- Database schemas and data models
- API implementation code
- Production credentials and secrets
- Proprietary datasets and benchmarks

All core product technology, content, and implementation details remain private and proprietary.
